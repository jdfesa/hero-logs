# HeroLogs Engineering Rule

Activation: **Always On**

Read and obey @../../AGENTS.md before changing this workspace.

The only authorized implementation scope is the active phase linked from
@../../docs/agent/PROJECT_STATE.md. Read that brief and only the product
documents it names. Do not combine phases, guess unresolved product decisions,
or declare completion without running the phase's verification.

Keep the application private and local-first. Never add sensitive permissions,
persist sensitive signals, change retention, invent score behavior, or introduce
cloud services unless the active phase explicitly authorizes the change.
